# QUAERYX Browser Extension

Search with QUAERYX from any webpage — free AI, 12+ sources, voice, file upload.

## Install in Chrome (Developer Mode)

1. Open Chrome → go to `chrome://extensions`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked**
4. Select this folder (`apps/browser-extension`)

## Features

- **Popup search** — click the QUAERYX icon in your toolbar to search instantly
- **Right-click search** — select any text on any webpage → right click → "Search QUAERYX for..."
- **Mode selector** — General, Academic, Code, News modes in the popup
- **Open full results** — button to open QUAERYX with full results, images, citations

## Icons

The `icons/` folder needs PNG icon files:
- `icons/icon16.png` (16×16)
- `icons/icon48.png` (48×48)  
- `icons/icon128.png` (128×128)

You can generate them from the QUAERYX SVG logo using any image converter.
